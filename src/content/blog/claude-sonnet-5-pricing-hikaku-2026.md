Claude Sonnet 5をAPIで使う予定があるなら、2026年8月31日は一度カレンダーに入れておいた方がよさそうです。

Anthropicの料金ページでは、Sonnet 5について<mark>2026年8月31日までのイントロ価格</mark>として、input $2 / output $10 per 1M tokens が示されています。9月以降は標準価格として input $3 / output $15 per 1M tokens になる、という案内です（2026年7月28日確認）。

この記事では、「結局どれくらい変わるのか」「自分の小規模API利用だと影響がありそうか」「Claude Sonnet 5を使い続けるべきか、他モデル比較を見るべきか」を、断定ではなく<mark>試算の目安</mark>として整理します。

<div class="box-warn"><div class="box-title">先に注意</div>
料金・提供条件・モデル仕様は変更される場合があります。この記事は2026年7月28日時点で確認できた公式料金ページの記載を元にした解説であり、最終的な課金額や節約効果を保証するものではありません。実際の請求前には必ず公式ページと自分の利用ログで確認してください。</div>

## 結論：9月以降はinput/outputともに50%上がる予定

Sonnet 5のAPI価格は、公式ページ上では次のように整理できます。

| 期間 | Input | Output | 備考 |
|---|---:|---:|---|
| 2026年8月31日まで | $2 / 1M tokens | $10 / 1M tokens | イントロ価格 |
| 2026年9月以降 | $3 / 1M tokens | $15 / 1M tokens | 標準価格 |
| 差分 | +$1 / 1M tokens | +$5 / 1M tokens | どちらも50%増 |

単価だけ見ると、inputもoutputも<mark>1.5倍</mark>です。ただし、請求額は単価だけで決まりません。実際には、入力トークン量、出力トークン量、キャッシュやバッチ等の利用有無、リトライ回数、プロンプト設計で大きく変わります。

つまり見るべきなのは「Claude Sonnet 5は高い/安い」という単純な話ではなく、<u>自分のワークロードでoutputがどれくらい出ているか</u>です。

## 月間利用量別：ざっくりどれくらい変わる？

以下は、キャッシュ等を考慮しない単純な概算です。実際の請求額ではなく、料金変更の大きさを見るための目安として読んでください。

| 利用イメージ | 月間input | 月間output | 8/31までの概算 | 9月以降の概算 | 差分 |
|---|---:|---:|---:|---:|---:|
| 小規模API検証 | 5M | 1M | $20 | $30 | +$10 |
| 記事・要約の定期処理 | 20M | 5M | $90 | $135 | +$45 |
| 小さなチャットbot運用 | 50M | 20M | $300 | $450 | +$150 |

小さく試している段階なら、差分は月数ドル〜数十ドルで収まる可能性があります。一方、チャットbotや自動化パイプラインのようにoutputが多い用途では、差分が見えやすくなります。

<div class="box-point"><div class="box-title">見直す順番</div>
まず見るべきは「月間output tokens」です。Sonnet 5はoutput単価の絶対額がinputより大きいため、長文回答・コード生成・レポート生成を大量に行う使い方ほど、9月以降の影響が出やすくなります。</div>

## 影響が小さそうな人・大きそうな人

### 影響が小さそうな人

- 月に数回、APIを試すだけ
- 短い分類・判定・抽出が中心
- outputが短く、長文生成をほとんどしない
- まだ本番ユーザーが少ない検証段階

この場合、9月以降に単価は上がっても、月額の差分は小さい可能性があります。モデル変更を急ぐより、まず利用ログを見て「どの処理が何tokens使っているか」を確認する方が安全です。

### 影響が大きそうな人

- チャットbotで長文回答を返している
- コード生成・レビュー・自動修正を頻繁に回している
- 記事、レポート、要約などの長文outputが多い
- 顧客数や実行回数が増えつつある

この場合は、9月を待たずに<mark>8月中に現行単価と標準価格の両方で試算</mark>しておくと判断しやすくなります。

## 「新tokenizerで35%増」などの話はどう扱うべきか

価格改定の話題では、tokenizerの違いによって同じテキストでもトークン数が変わる可能性が語られることがあります。ただし、この記事の公開前確認では、公式料金ページ上で具体的な増加率を一次情報として確認できませんでした。

そのため本記事では、「何%増える」といった断定は置きません。実務上は、次のように扱うのが安全です。

1. いまの代表的なプロンプトを数本選ぶ
2. Sonnet 5で実行し、input/output tokensをログに残す
3. 8/31までの単価と9月以降の単価で両方試算する
4. 長文outputが多い処理から優先して見直す

数字が確認できない噂を前提にするより、<u>自分のログで再計算する</u>方が外しにくいです。

## Claude Sonnet 5を選び続けるべきケース

料金だけでモデルを選ぶと、かえって総コストが上がることがあります。たとえば、安いモデルに変えた結果、失敗率が上がる・リトライが増える・人間の確認が増えるなら、単価差は簡単に相殺されます。

Sonnet 5を選び続ける理由があるのは、次のようなケースです。

- コーディング、設計、長文推論などで品質差が明確に出る
- 1回の失敗や修正コストが大きい
- 既存プロンプトがClaude前提で安定している
- モデル変更の検証コストが、当面の料金差より大きい

特に本番運用中のプロダクトでは、「単価が上がるから即乗り換え」ではなく、品質・失敗率・応答速度・運用ログを合わせて見た方が安全です。

## 他モデル比較を見るべきケース

逆に、他モデル比較をした方がよいケースもあります。

- 大量の短文分類や抽出が中心
- 回答品質より処理量・単価が重要
- outputが定型で、多少の表現差が問題になりにくい
- 月間利用額がすでに数百ドル以上ある
- 9月以降の試算で予算上限を超える

この場合は、Claude Sonnet 5だけで悩むより、OpenAI、Gemini、DeepSeek、ローカルLLMなども含めて、同じサンプルタスクで横並びに比較するのが現実的です。

AIツールや学習サービス全体の比較を見たい場合は、[AI番付の生成AIスクール比較](/ai-school)も参考にしてください。APIモデルの直接比較とは目的が違いますが、「何を学ぶ/何に使うか」から整理したい人向けの入口です。

## 8月中にやるとよい3つの確認

### 1. 代表タスクごとのtokensを記録する

まずは、全タスクを細かく分類する必要はありません。利用量の多い上位3〜5タスクだけで十分です。

- チャット回答生成
- 記事・要約生成
- コード生成
- 分類・抽出
- 長文資料の読み込み

それぞれについて、input/output tokensと実行回数をざっくり出します。

### 2. 9月以降の単価で再計算する

計算式はシンプルです。

<div class="box-data"><div class="box-title">概算式</div>
月額目安 = input tokens(M) × $3 + output tokens(M) × $15<br>
※2026年9月以降の標準価格を使った単純計算。キャッシュ、割引、契約条件、為替は別途確認してください。</div>

現在の支払い額を見るだけでは、イントロ価格終了後の影響を見落とす可能性があります。必ず標準価格側でも試算してください。

### 3. 代替モデルに変える条件を先に決める

モデル比較は、目的が曖昧だと終わりません。先に条件を決めるのがおすすめです。

- 月額がいくらを超えたら比較するか
- 失敗率が何%以内なら安いモデルに移すか
- どのタスクだけ代替モデルに逃がすか
- 人間の確認が増えるなら許容できるか

「全部乗り換える」より、「分類だけ別モデル」「長文推論だけSonnet 5」のように分ける方が現実的です。

## よくある質問

**Q1. 8月中に使えば必ず得ですか？**  
必ず得とは言えません。8月中はイントロ価格ですが、使う必要のない処理を増やせば当然コストは発生します。必要な検証を前倒しする、という程度に捉えてください。

**Q2. 9月以降、Claude Sonnet 5は高すぎますか？**  
用途次第です。短文・大量処理では高く感じやすい一方、コーディングや複雑な推論で失敗が減るなら、標準価格でも採算が合う場合があります。実測必須です。

**Q3. tokenizerの影響は見なくていいですか？**  
見た方が安全です。ただし、確認できない増加率を前提にするのではなく、自分の代表プロンプトでtokensを測る方が実務的です。

**Q4. 個人開発者は何から始めればいいですか？**  
まずは直近30日のAPIログから、input/output tokensとタスク別の実行回数を出してください。その上で、9月以降の単価で再計算するのが最短です。

## まとめ：価格改定は「モデル選定」より先に「利用ログ確認」

Claude Sonnet 5のイントロ価格は、2026年8月31日まで input $2 / output $10 per 1M tokens。9月以降は標準価格として input $3 / output $15 per 1M tokens になる予定です。

単価差はinput/outputともに50%ですが、実際の影響はワークロード次第です。特に長文outputが多い処理では差分が出やすいため、8月中に現行ログを使って標準価格側の試算をしておくと判断しやすくなります。

一方で、安いモデルへの乗り換えが常に正解とは限りません。品質低下、リトライ、人間の確認が増えれば、見かけの単価差は消えます。まずは利用ログを見て、影響が大きいタスクから順に比較するのが安全です。
